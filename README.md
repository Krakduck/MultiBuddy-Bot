# MultiBuddy Bot 
Телеграмм бот для групп. Помогает считать общие расходы, долги и многое другое. Имеется файл amvera.yml для автоматической настройки хостинга бота на сервисе amvera

# Стек
* asyncio
* aiogramm 3.13.1
* aiosqlite 0.20.0
* Python 3.11

# Функции
* Регистрация
* информация профиля
* Запись расходов
* Оплата долгов
* Общий/рандомный пинг
* Сохранение/показ цитат (сообщений)
* Создание событий

# Команды(/...)
* /profile - информация о пользователе
* /del_profile - удаление учетной записи
* /spent - записать расходы
* /debts - оплатить долг
* /clear-debt (для админов) - списание всех долгов
* /random - отметить случайного человека
* /all - отметить всех
* /help - помощь с функциями
* /save - сохранить сообщение. Команда присылается в ответ на сообщений, которые нужно сохранить
* /citations - показать список сохраненных сообщений
* /event - создать событие

# Установка
1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/Krakduck/MultiBuddy-Bot.git](https://github.com/Krakduck/MultiBuddy-Bot.git)
   cd project-name
   
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt

3. Настройте переменные окружения:
   Cоздайте файл .env в корневой директории на основе шаблона:
   ```bash
   cp .env.example .env
   
Откройте файл .env и укажите свои данные:
BOT_TOKEN — токен Telegram-бота, полученный у @BotFather
ADMIN_ID — ваш числовой Telegram ID (можно узнать через @userinfobot)
   
4. Запустите проект:
   ```bash
   python main.py
